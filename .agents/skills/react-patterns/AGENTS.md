# React Patterns - Agent Instructions

## Skill Overview
This skill provides comprehensive React 18 patterns including hooks, concurrent features, Suspense, and modern TypeScript development patterns.

## When to Activate
- Building or refactoring React components
- Implementing state management
- Working with React 18 features (Concurrent Mode, Suspense)
- Performance optimization
- Component architecture decisions

## Key Capabilities
- React 18 Concurrent Features and Suspense
- Modern hooks (useState, useEffect, useMemo, useCallback, useReducer)
- Automatic batching and transitions
- Performance optimization patterns
- TypeScript patterns

## Usage Pattern
```
Reference this skill when:
1. Creating new React components
2. Refactoring component architecture
3. Implementing forms with Server Actions
4. Optimizing component performance
5. Working with async/streaming data
```
