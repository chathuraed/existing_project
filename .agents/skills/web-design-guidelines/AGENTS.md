# Web Design Guidelines - Agent Instructions

## Skill Overview
This skill reviews UI code for Web Interface Guidelines compliance, focusing on accessibility, UX best practices, and modern web standards.

## When to Activate
- User asks to "review my UI"
- Accessibility audit requests
- Design system compliance checks
- UX review requests
- "Check my site against best practices"

## Key Capabilities
- Accessibility (WCAG) compliance review
- UI/UX best practices validation
- Design consistency checks
- Performance implications of design choices
- Responsive design patterns

## Usage Pattern
```
Reference this skill when:
1. Reviewing UI components
2. Auditing accessibility
3. Checking design system adherence
4. Validating responsive layouts
5. Pre-deployment UI checks
```
