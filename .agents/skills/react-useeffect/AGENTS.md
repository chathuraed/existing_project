# React useEffect - Agent Instructions

## Skill Overview
This skill teaches when NOT to use useEffect and provides better alternatives based on official React documentation.

## When to Activate
- Reviewing code that uses useEffect
- Refactoring unnecessary effects
- Handling derived state
- Data fetching patterns
- State synchronization issues

## Key Capabilities
- Identifying unnecessary effects
- Converting effects to derived state
- Using proper React patterns (useMemo, key prop)
- Effect cleanup patterns
- Data fetching best practices

## Usage Pattern
```
Reference this skill when:
1. Code review includes useEffect
2. Debugging state synchronization issues
3. Refactoring performance problems
4. Converting class components to hooks
5. Teaching React best practices
```
